Connect Firebase

This app stores prayers in your church's Firebase Realtime Database and signs you in with Google. Add your project's keys once, then everyone on staff signs in with their Google account.

  1. Create a project at console.firebase.google.com
  2. Authentication → Sign-in method → enable Google
  3. Build → Realtime Database → Create Database (locked mode)
  4. Paste the security rules below into the database's Rules tab
  5. Copy your web-app config into firebase-config.js (include databaseURL)
  6. Authentication → Settings → Authorized domains → add the domain you deploy to
